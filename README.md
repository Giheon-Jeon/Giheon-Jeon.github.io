# 🌿 Giheon's Link Tree

> **인스타그램 및 SNS 프로필 게시용 인터랙티브 링크트리 페이지**
>
> 개인 소셜 미디어 채널, 블로그, 이메일 복사 등 다양한 링크를 한곳에 모아 제공하는 반응형 웹 애플리케이션입니다.

<br />

## ✨ 주요 특징 (Features)

- **🎨 인터랙티브 배경 애니메이션**: 따뜻한 톤의 그라데이션 블롭이 끊임없이 움직이고, 마우스/터치 위치에 반응하는 패럴랙스 & 탭 리플 효과
- **🃏 인터랙티브 카드**: 등장 시 순차 애니메이션(stagger), 탭/클릭 시 스케일 피드백, 마우스 위치에 반응하는 3D 틸트 & 글로우 효과
- **📱 모바일 퍼스트 반응형**: 터치 인터랙션 중심으로 설계, 모든 화면 크기에서 자연스러운 레이아웃
- **✉️ 이메일 복사 토스트**: '이메일 복사하기' 버튼 클릭 시 클립보드 복사 기능 및 애니메이션 토스트 알림
- **⚡ Vite 기반 빠른 빌드**: React + Vite + Tailwind CSS 조합으로 빠른 개발/빌드 속도

<br />

## 🛠️ 기술 스택 (Tech Stack)

- **Core**: React 18, Vite 5
- **Animation**: Framer Motion
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages (GitHub Actions로 자동 빌드/배포)

<br />

## 🚀 로컬 개발

```bash
npm install
npm run dev      # 개발 서버 실행 (http://localhost:5173)
npm run build    # 프로덕션 빌드 (dist/)
```

<br />

## 🔗 배포 주소 (Demo)

`main` 브랜치에 push되면 GitHub Actions가 자동으로 빌드하여 GitHub Pages에 배포합니다.
