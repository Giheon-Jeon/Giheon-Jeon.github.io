# 🌿 Giheon's Link Tree

> **인스타그램 및 SNS 프로필 게시용 심플 링크트리 페이지**
> 
> 개인 소셜 미디어 채널, 블로그, 이메일 복사 등 다양한 링크를 한곳에 깔끔하게 모아 제공하는 반응형 웹사이트입니다.

<br />

## ✨ 주요 특징 (Features)

- **🎨 미니멀 & 감성 디자인**: 따뜻한 톤의 배경 그라데이션과 부드러운 호버 애니메이션이 적용된 반응형 UI 디자인
- **📱 반응형 웹 디자인**: 모바일 화면에 최적화되어 있으며, 태블릿 및 데스크톱 환경에서도 안정적인 레이아웃 제공
- **✉️ 이메일 복사 토스트**: '이메일 복사하기' 버튼 클릭 시 클립보드 복사 기능 및 깔끔한 토스트 알림창 출력
- **⚡ 최적화된 로딩 속도**: 빌드 도구 없이 HTML, Vanilla CSS, Tailwind CSS(CDN)만 사용하여 가볍고 빠른 초기 로딩

<br />

## 🛠️ 기술 스택 (Tech Stack)

- **Core**: HTML5, JavaScript (ES6+)
- **Styling**: Tailwind CSS (via CDN), CSS3 Custom Variables & Keyframes
- **Deployment**: GitHub Pages
